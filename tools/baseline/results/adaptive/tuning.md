# Tuning rounds

Round 1: express before planning allows up to two [auto] risk-free requirements (as apply already did, C20); a project `check` command counts as the project's tests; a document (.md, .txt, .rst) is never a risk path. Fixed alongside, as defects: the benchmark driver answers multi-select questions, and the router opens with the rule that no project file changes before approval. Result: all 14 cells pass; failing-check-fix moved from standard to express on both models (Sonnet 1.06 to 0.35 USD, Opus 0.92 to 0.53 USD); express cells cost 2.06x to 2.8x plain, except safety-secret on Sonnet (5.0x); no cell is within 2x.

Round 2 was considered and not run: the one change left that the results pointed to (a phase that only writes documents is risky only for secrets) conflicts with approved check C20, under which a risk named by a requirement counts whatever the files. The misses are stated in docs/benchmark.md.
